## 2026-07-02 - Prevent Asyncio Event Loop Blocking\n**Learning:** Telegram bot framework uses asyncio. Synchronous network calls to external APIs (like Gemini via `model.generate_content`) block the entire event loop, severely degrading concurrent user request handling.\n**Action:** Always use the asynchronous versions of library methods (e.g., `model.generate_content_async`) inside `async def` functions and `await` them in Telegram bot handlers.
