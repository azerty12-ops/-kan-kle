## 2024-05-18 - Async API calls in Telegram Event Loop\n**Learning:** The telegram bot runs on an `asyncio` event loop. Synchronous calls to the Gemini API (`self.model.generate_content`) completely blocked the event loop, preventing the bot from processing multiple requests concurrently.\n**Action:** Always use the async version of external API calls (e.g., `await self.model.generate_content_async`) inside any async context like telegram bot handlers.
