## 2024-06-13 - [CRITICAL] Missing Authentication on Personal Bot
**Vulnerability:** The Telegram personal assistant bot had no authentication mechanism, allowing any user on Telegram who discovered the bot's username to issue commands, modify the user's agenda, access their compta, and incur Gemini API costs.
**Learning:** Personal bots, despite being "private" by intent, are publicly accessible on the Telegram network unless explicitly restricted. Without an authorization check, they act as an open proxy to the owner's personal data and paid APIs. The most robust way to secure a python-telegram-bot application is using a global `TypeHandler` with `group=-1` to intercept and authorize all `Update` objects before any functional handlers run.
**Prevention:** Always implement a whitelist approach (e.g., `ALLOWED_USER_ID`) for personal or internal bots. Enforce this check globally using middleware (like `TypeHandler` in `python-telegram-bot`) to ensure no new handler accidentally bypasses authentication.
