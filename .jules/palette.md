## 2024-07-02 - Interactive Reply Menu for Telegram Bot
**Learning:** Using typed commands (e.g., `/agenda`) adds unnecessary friction, particularly on mobile devices. A permanent, discoverable menu enhances user experience.
**Action:** Implemented `ReplyKeyboardMarkup` for core commands to reduce typing friction and improve discoverability. In the future, I should always default to an interactive menu for frequently-used commands in a conversational interface.
