## 2024-05-24 - Interactive Menus for Conversational Interfaces
**Learning:** In text-based conversational interfaces (like Telegram bots), requiring users to type commands manually introduces friction, especially on mobile devices. Discoverability of features is also poor if users have to recall commands or check a `/help` menu.
**Action:** Always provide interactive elements like `ReplyKeyboardMarkup` for core commands. This reduces cognitive load, prevents typing errors, and surfaces the bot's capabilities immediately upon start.
